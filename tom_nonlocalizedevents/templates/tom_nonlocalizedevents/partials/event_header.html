{% comment %} This partial renders the event header. The header shows the event's identity (its id, its state and links to the external services for the event). There is one tab for each alert the event has received. The attributes of the selected alert are shown. There is a link to each workflow step. Clicking an alert tab updates the event header with values from the selected alert. The clicked-upon alert tab sends an htmx request whose hx-target is the outermost div of this partial. That means the response replaces the whole (outermost) div, updating every part of the page. The div contains every part that changes and every part that changes must be in that outermost div. The sky map is the exception: it changes with the selected alert, but it stays outside the div to preserve the Aladin viewer. Instead, the sky map is updated by swapping its data element out of band (see partials/event_summary_update.html). {% endcomment %}
